# Haoming (Harvey) Chen

My personal website: [hc-sgw.github.io](https://hc-sgw.github.io).

Built with [al-folio](https://github.com/alshedivat/al-folio) and hosted on GitHub Pages.

To preview locally, run `bundle install` and `bundle exec jekyll serve`.

To add a portrait, put the image in `assets/img/` and update `profile.image` and `profile.alt` in `_pages/about.md`.
